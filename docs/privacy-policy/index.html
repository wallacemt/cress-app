Cress — Privacy Policy

Last updated: November 20, 2026

Cress is an offline-first desktop app for musical practice. This page explains what data Cress handles and, just as importantly, what it does not do.

Microphone

Cress uses your microphone for its tuner, metronome listening features and recorder. All audio is processed locally, on your computer. Cress never transmits microphone audio or recordings to any server — there is no backend that receives your audio.

Recordings and local data

Practice sessions, recordings (.wav files), your repertoire, scores (PDF files) and your profile (name, instrument, tuning preferences) are stored only on your computer, in your Windows user profile's application data folder. Cress has no account system and no cloud sync — this data never leaves your device unless you copy it yourself.

No telemetry, no analytics, no tracking

Cress does not collect usage analytics, does not use advertising or tracking SDKs, and does not profile its users.

Automatic updates

Cress checks GitHub's release servers to see if a newer version is available, and can download and install that update. This check only exposes the information any HTTP request makes (such as your IP address to GitHub's infrastructure) and the app's current version — no personal or practice data is included in this request.

Children's privacy

Cress does not knowingly collect personal information from anyone, regardless of age, since all data stays local to the device and is never transmitted.

Your control over your data

You can delete any recording, piece or session from within the app. Uninstalling Cress, or deleting its application data folder, removes all locally stored data.

Changes to this policy

If this policy changes, the updated version will be published at this same URL with a new "last updated" date.

Contact

Questions about this policy can be opened as an issue on the Cress GitHub repository.

Cress — Política de Privacidade

Última atualização: 20 de novembro de 2026

Cress é um aplicativo desktop de prática musical, offline-first. Esta página explica quais dados o Cress trata e, igualmente importante, o que ele não faz.

Microfone

O Cress usa o microfone para o afinador, para recursos de escuta do metrônomo e para o gravador. Todo o áudio é processado localmente, no seu computador. O Cress nunca transmite áudio do microfone ou gravações para nenhum servidor — não existe backend que receba seu áudio.

Gravações e dados locais

Sessões de prática, gravações (arquivos .wav), seu repertório, partituras (arquivos PDF) e seu perfil (nome, instrumento, preferências de afinação) são armazenados apenas no seu computador, na pasta de dados de aplicativo do seu perfil do Windows. O Cress não tem sistema de conta nem sincronização em nuvem — esses dados nunca saem do seu dispositivo, a menos que você mesmo os copie.

Sem telemetria, sem analytics, sem rastreamento

O Cress não coleta dados de uso, não usa SDKs de publicidade ou rastreamento, e não cria perfis de usuários.

Atualizações automáticas

O Cress verifica os servidores de release do GitHub para checar se há uma versão mais recente disponível, podendo baixar e instalar essa atualização. Essa verificação expõe apenas o que qualquer requisição HTTP expõe (como o seu IP para a infraestrutura do GitHub) e a versão atual do app — nenhum dado pessoal ou de prática é incluído nessa requisição.

Privacidade de crianças

O Cress não coleta intencionalmente informações pessoais de ninguém, independentemente da idade, já que todos os dados permanecem locais ao dispositivo e nunca são transmitidos.

Seu controle sobre seus dados

Você pode excluir qualquer gravação, obra ou sessão de dentro do app. Desinstalar o Cress, ou apagar sua pasta de dados de aplicativo, remove todos os dados armazenados localmente.

Mudanças nesta política

Se esta política mudar, a versão atualizada será publicada nesta mesma URL com uma nova data de "última atualização".

Contato

Dúvidas sobre esta política podem ser abertas como uma issue no repositório do Cress no GitHub.
